# eurth-map

The web app for the Eurth interactive map: React + Vite, no map library. The project overview is in the `README.md` one folder up.

```bash
npm install
npm run dev        # development server at http://localhost:5173
npm run build      # production build in dist/
npm run preview    # serve dist/ at http://localhost:4173
npm run lint
```

- `src/` — components, hooks, data and utilities
- `public/` — the base map, the overlay images and the nation shapes. Most of it is generated by the scripts in `../overlay-tools/`; do not edit those files by hand
- `api/suggest.js` — the serverless function behind "Suggest an edit". It runs on Vercel and under `vercel dev`, not under `npm run dev`

Hosting, the token the function needs and local testing of the form are in `../DEPLOY.md`.
